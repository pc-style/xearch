Search what was said on X

Xearch keeps a full-text index of the public posts from every X account it has imported. Type a few words to find a post you half remember, start with @handle to see what one account said about a topic, and sort by relevance, engagement, likes, newest or oldest. Every result links to the original post on x.com, with its replies, quotes and link previews.

It is free and needs no account. Agents and scripts can run the same search through the MCP server, the REST API and its OpenAPI description, or a plain search link.
